# Binance Paper Trading Lab

A research environment for training/evaluating the trading agent against **real public Binance market data** while keeping execution entirely virtual.

## Components

- `index.html`: browser dashboard; refreshes public Binance REST data, displays 1m/5m candles, order-book imbalance, basic candle features, and a virtual account.
- `train.py`: downloads recent real 1-minute Binance spot candles and runs a fee-aware paper backtest.
- `latest_backtest.json`: generated by the scheduled workflow.
- `.github/workflows/binance-paper-training.yml`: scheduled research run every 15 minutes plus manual dispatch.

## Safety boundary

This lab uses Binance **public market-data endpoints only**. It does not contain API keys, does not authenticate, and does not submit real orders. Paper orders modify only the browser's local virtual account.

The current backtest is deliberately a baseline. It must not be interpreted as evidence of profitability. Future training should add walk-forward validation, out-of-sample splits, realistic spread/slippage, order-book snapshots, open interest/funding, imbalance features, and the candlestick engine.

## Run locally

Open `index.html` in a modern browser with network access, or serve `trading_lab/` from a local static server. For the research backtest:

```bash
python trading_lab/train.py
```

The default paper capital is configurable in the dashboard and the training script.
